# FrutaRadar Perú · sitio público

Demo estática de precios mayoristas oficiales y una instantánea de precios online de supermercados en Lima. Disponible en https://gonzalo1256.github.io/frutaradar-peru-029/. Cada precio enlaza su boletín o ficha comercial, con fecha, unidad y canal. La guía describe filtros, resultados y límites; la única IA permitida es Codex o ChatGPT. La instantánea retail no confirma stock por distrito y la copia pública no se sincroniza automáticamente con los recolectores locales.
